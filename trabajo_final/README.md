# Programa de curso

1. Introducción a Machine Learning. Definiciones. Ciclo de vida de un proyecto de Aprendizaje Automático. Metodología para construir modelos.
2. Aprendizaje supervisado. Clasificador KNN. Medidas de distancia. Encontrando alos vecinos. Métodos de Ajuste de los hiperparámetros. Frameworks de búsqueda.
3. Máquinas de vectores de soporte. Maximal Margin Classifier. Clasificador deVector de soportes. Máquinas de vectores de soporte en regresión.
4. Árboles de decisión. Árboles de clasificación y árboles de regresión.
5. Métodos de ensamble. Modelos que votan. Bagging. Bosques aleatorios.Boosting.
6. Aprendizaje No Supervisado. Clustering. K-Means. Hierarchical clustering.Modelo de Mixtura Gaussiana. Suma de cuadrados intracluster. Índice de lasilueta. Fuerza de predicción.
7. Calibración de modelos. Discriminación vs. Calibración. Métodos deCalibración.

# Trabajo práctico final

## Aspectos a considerar

- El enfoque principal de este trabajo es la etapa de Machine Learning: la aplicación,manejo y evaluación de modelos.
- Si bien el procesamiento de datos y el feature engineering son pasos esenciales para laaplicación del modelo, en esta materia tendrán menor relevancia.
- Se deberá justificar la elección de las herramientas utilizadas y presentar un desarrolloteórico correcto.
- No olvidar incluir las referencias bibliográficas correspondientes.

## Estructura sugerida

- Introducción al problema (contexto, tipo de problema) ⟶
- Datos (descripción y preparación) ⟶
- Entrenamiento (baseline, algoritmos, justificación) ⟶
- Métricas y evaluación ⟶
- Conclusiones
